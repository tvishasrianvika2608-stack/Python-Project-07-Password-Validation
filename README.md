# Project 7: Password Policy Validation Engine

## Problem Description
This project evaluates password strings based on specified password security rules. It checks minimum length, uppercase letters, lowercase letters, digits, special characters, repeated consecutive characters, and prohibited substrings. It also explains the conditions that are not satisfied.

## Programming Language
Python

## Concepts Used
- Variables and data types
- Strings and string operations
- Lists
- For loops
- Conditional statements (if, else)
- Logical operators
- User input and output

## Files Included
- `Question_07_Password_Validation.py` – Python source code
- `Screenshots/` – Code and output screenshots

## How to Run
1. Download the Python file.
2. Open it using Python or VS Code.
3. Run the program.
4. Enter a sample password.
5. View the validation result and any failed conditions.

## Conclusion
The program checks passwords against the specified security rules and displays whether the password is valid or invalid, along with the reasons for any failed conditions.
